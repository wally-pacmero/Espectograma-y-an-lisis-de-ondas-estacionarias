# Espectograma-y-an-lisis-de-ondas-estacionarias
Código para generar una interfaz para visualizar un espectograma y análisis de ondas estacionarias
El código hace uso de la detección de patrones repetitivos para encontrar en el audio insertado una onda estacionaria. Hace uso de la libreria matplotlib para mostrar la información en una interfaz visual fácil de analizar, hace uso de la Transformación Rápida de Fourier (FTT) para optimizar la autocorrelación.
